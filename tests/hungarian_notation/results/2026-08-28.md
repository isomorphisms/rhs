# Hungarian relation-vector results — 2026-08-28

This is the first real-model run of the controlled Hungarian-notation
difference-vector experiment.

For every identifier edge, the measured object is

```text
delta = embedding(prefix + stem) - embedding(stem)
```

All comparisons occur inside one model's own coordinate space. Raw coordinates
are never compared across models. Every identifier is encoded by attention-mask
mean pooling of the final hidden state.

The fixture contains 24 historical Hungarian edges across six declared facets,
plus four synthetic capitalization-control edges. Classification uses
leave-one-edge-out facet prototypes.

## Main results

| Model | All edges | Hungarian only | final D/d alignment | zero edges | mean held-out margin |
|---|---:|---:|---:|---:|---:|
| CodeBERTa-small-v1 | 28/28 (100.0%) | 24/24 (100.0%) | 0.833 | 0 | 0.382 |
| microsoft/codebert-base | 26/28 (92.9%) | 22/24 (91.7%) | 0.509 | 0 | 0.181 |
| all-MiniLM-L6-v2 | 13/28 (46.4%) | 13/24 (54.2%) | undefined | 4 | 0.054 |
| bert-base-cased | 7/28 (25.0%) | 3/24 (12.5%) | 0.809 | 0 | -0.001 |
| bert-base-uncased | 6/28 (21.4%) | 6/24 (25.0%) | undefined | 4 | -0.076 |

The held-out margin is the cosine with the correct leave-one-out facet
prototype minus the cosine with the strongest wrong facet. Positive is good.

The undefined capitalization entries are exact zero vectors. That is the
correct result for tokenizers that remove case information.

## Concrete errors

CodeBERT missed only two held-out edges:

- `Buffer -> cbBuffer`: classified as column rather than byte-count.
- `Cursor -> iCursor`: classified as column rather than index.

Both were borderline: CodeBERT's worst margin was only -0.005.

The general BERT models repeatedly confused the intentionally neighboring
pairs WORD/DWORD and row/column. BERT-cased represented capitalization
consistently while largely failing to separate the historical Hungarian
relations.

## What this establishes

The code-oriented models, especially CodeBERTa, contain stable and separable
directions for these controlled identifier transformations. The uncased
capitalization controls fail exactly as they should, so the probe is sensitive
to a known loss of information rather than manufacturing a direction.

This run establishes repeatable relation geometry. It does **not yet**
distinguish knowing the lexical rule “add `cb`” from knowing that `cb`
means “count in bytes.” The next semantic-grounding control should compare each
abbreviated direction with an explicit full-word direction, for example
`cbBuffer` against `bufferByteCount`, and against matched nonsense prefixes.
